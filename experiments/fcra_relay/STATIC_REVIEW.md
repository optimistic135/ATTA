# FCRA-Relay 静态审查

未执行 Python、CLI、编译、单元测试、推理、训练或实验。以下仅为源码与差异检查，不代表运行验证通过。

| 检查项 | 源码检查结论 |
| --- | --- |
| 范围 | 独立新增包；D=0/20/50/100 × 三公共 seed，12 个任务；没有其他方法调度 |
| Source | 复用严格 Photo checkpoint 加载；不调用源训练或覆盖原 checkpoint |
| 流 | Art_1/Cartoon/Sketch/Art_2/Photo；真实域名只在 stream.py 统计，不进入 relay 决策 |
| 重复图像 | FastDataLoader sampler 索引加域偏移，物理 ID 全流唯一；重复遇见计分但不重复查询同一图像 |
| 标签时序 | select_current 和查询上下文先固定，oracle.release 后才更新 received 与语义记忆；D=0 亦如此 |
| 校准泄漏 | 校准使用固定查询时预测；没有用当前更新后的预测冒充查询时证据；当前真标签不回写历史预测 |
| 启动 | relay 使用保守先验；没有校准事件也可传播，不需要先完成第二轮候选审计 |
| 门控恢复 | 满足邻域条件但被可靠性门控拒绝的候选也保存待校准信息，避免永久关闭 |
| 等待期学习 | 没有 received 时仍执行四次当前图像更新；不再以真实记忆非空作为全部训练前提 |
| Pending 缓存 | 等待期模型变化后也刷新所有查询 anchor 特征，避免聚类使用过时特征 |
| 目标隔离 | 当前 EMA、源预测和 relay 目标 no_grad；只对学生 layer4/分类头反向传播 |
| 纠错 | relay 跨全部真类别检索，不要求与当前伪类别一致；目标可替换高置信 EMA 错误 |
| 记忆 | 真实记忆完整保留，按返回数量刷新缓存；近期无标签 buffer 有界并重新生成目标 |
| 损失权重 | 真实 CE=1，当前 KL=0.5，未传播源约束 KL=0.05；不由池大小决定 |
| 预算 | 四次当前/混合更新加最多26次纯真监督，单批上限30；无标签不虚构监督，不回填未用额度 |
| 梯度 | 有限损失检查；非有限梯度范数报错；梯度裁剪后更新；EMA不进入optimizer |
| 随机性 | minibatch/增强使用独立CPU Generator；各任务初始化seed一致、同延迟从相同源权重独立开始 |
| 统计 | 首三域平均先逐seed计算再汇总；样本std；N/A不记成0；返回率/跨域率/跨阶段率分母明确 |
| 汇总完整性 | 只在12个身份一致的结果齐全后输出summary；按阶段另写stage_summary.csv |
| 诊断 | fixed/broken仅用已固定输出做离线计分，不反馈到模型；raw模型已被Relay训练，不作独立baseline |
| 双卡 | 复用scheduler，一卡一个worker；GPU参数互斥、唯一、非负；worker验证CUDA |
| 结果保护 | 输出新目录，原数据、原方法、旧结果不覆盖；未返回队列不在末尾冲刷 |

静态修正包括：区分候选可校准资格与实际传播采用资格；移除过时审计汇总列；注册固定计算计数schema；为新增前三域/返回比例字段核对result与summary的一致性。

仍需服务器验证：Torch版本/模型/checkpoint兼容性、layer4梯度数值、CUDA内存、近邻覆盖和可靠性、等待期净适应、长延迟精度及耗时。新方法创新性和有效性都需要进一步文献比较与对照实验支持。
