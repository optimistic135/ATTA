# SimATTA D=100：最小根因诊断方案

## 目标与来源

根据已有PACS结果，长延迟下降明显，但此前改进算法同时修改多个机制，不能据此确定原SimATTA的根因。本方案只回到原SimATTA，检验“真实监督是否帮助当前任务”以及“伪监督是否削弱这种帮助”。方案依据现有SimATTA源码、延迟oracle和此前用户提供结果制定，不预设实验结论。

遵循 scientific-toolkit-skill 的可复现、最小改动原则及 research-writing-skill 的证据边界原则。依用户要求，本地不执行Python或实验，仅静态检查；运行验证留在服务器。

## 唯一主实验

Photo(source) → Art → Cartoon → Sketch，batch=32，D=100，seed=110/123/456。每个seed独立加载同一Photo checkpoint，保持原SimATTA熵/聚类选样、低熵固定教师伪标签、完整返回标签池和原PACS早停训练。

不运行D=0/20/50、不训练新算法、不调整查询策略。每张GPU同时一个主任务。沿用先预测后释放/更新、全流连续时钟、流末不flush。

## 五个诊断时刻

固定候选起点为0-based step 100、130、170、210、240；各在起点起的10个batch内，遇到首个“有新标签返回且原伪标签池非空”的时刻触发一次。若条件始终不满足则跳过并记录，不用替代真标签伪造PSEUDO分支。

这些时刻覆盖首次反馈附近、Cartoon末尾、Sketch中段和Sketch可能开始收到本域反馈的后段。不同seed实际触发时刻允许不同，比较只在同一seed、同一快照内严格配对。

## 四分支，控制两个监督目标

从返回标签参与当前主模型更新前的同一快照分出：

| 分支 | 十次短更新使用的目标 |
| --- | --- |
| SKIP | 不更新，作为同状态参照 |
| TRUE | 完整已返回真标签池的平均CE |
| PSEUDO | 原SimATTA伪标签池的平均CE |
| MIX | 原SimATTA alpha × TRUE + (1-alpha) × PSEUDO |

TRUE与MIX使用相同真标签池、相同十个训练minibatch；PSEUDO与MIX使用相同伪标签抽样。alpha根据当时真/伪记忆数量及cold_start按原规则计算。采用原学习率、SGD momentum=0.9；所有分支从空优化器状态开始，因为原SimATTA每个batch也重建优化器。

TRUE不是只训练新标签：这样能控制TRUE/MIX的唯一主要差异为监督混合，而不是同时改变真标签数据集。记录fresh_count和fresh_draws，用于检查当批新反馈实际被抽中多少次；本实验不能单独识别某一个新标签的边际收益。

## 怎样评价

短更新后冻结分支，评价接下来的10个batch，**不包括触发batch、不再继续训练分支**。四分支评价同一批图像与标签，未来真标签只计分，不参与分支训练、查询、选择、超参数调整或主模型训练。

记录：

1. 后续准确率、相对SKIP的净收益（pp）、改对/改错样本数。
2. 同一历史真实记忆上的更新前后准确率，作为历史拟合代理。
3. 初始真/伪监督对全部可训练参数的梯度余弦、原始梯度范数及加权伪/真范数比。
4. 当前真标签池、新返回标签数量、同域比例、alpha和初始模型哈希。

十步更新和十批观察窗口是预先固定的局部诊断尺度，不等同于原模型一整个batch的早停训练效果。

## 如何据结果决定模块方向

| 观察 | 支持的解释 | 下一步方向 |
| --- | --- | --- |
| TRUE优于SKIP，但MIX较TRUE差 | 可用真实监督收益在混合目标中被削弱 | 检查监督权重与伪标签可靠性；负梯度余弦可补充冲突证据 |
| TRUE改善历史记忆，但不改善后续样本 | 历史拟合收益未转化为当前泛化收益 | 研究监督与当前环境的错位 |
| TRUE/PSEUDO/MIX均不如SKIP | 此处短更新整体不利 | 检查更新强度、模型状态与分布变化 |
| PSEUDO优于SKIP、TRUE无益 | 当前伪监督可能更贴合当前样本 | 分析历史监督相关性与选择性使用 |
| 后续局部干预有益，整流仍差 | 等待期或其他时段可能占主要损失 | 结合首次反馈前错误统计再研究等待期 |

这些是条件解释，不是自动根因判决。TRUE与MIX差异同时包含缩放和方向影响；cos<0不单独证明负迁移。历史记忆上的准确率是训练集拟合指标，不能当成泛化证据。反馈前后样本域不同，不能直接相减作为反馈因果效果。

## 统计与边界

完整窗口先在每个seed内按相同未来样本数加权计算准确率和配对差，再对三个seed报告均值±样本标准差。事件不是独立seed重复；不把数千样本当作数千次独立实验。缺失和不完整窗口排除，记录有效n。

该实验能提供有限时刻、固定查询轨迹下的局部目标干预证据，不能量化D=100所有损失的百分比，也不能单独证明延迟本身的因果效应或新模块一定有效。
