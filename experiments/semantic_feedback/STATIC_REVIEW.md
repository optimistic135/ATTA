# 静态审查记录

范围：只阅读新增代码、复用接口和差异；未执行 Python、导入、语法编译、CLI help、测试、训练或实验。以下是源代码层面的检查结论，不能替代服务器运行验证。

| 检查项 | 静态依据与实现 |
| --- | --- |
| 未到期真值隔离 | `select_queries` 只收到图像和 ID；融合只在 oracle release 后的 hook 接收标签 |
| 预测先于更新 | 四分支概率在 `select_queries` 缓存；评分读取缓存，融合/监督更新不能改写当前批预测 |
| 返回先校准再监督 | hook 中重新计算当前 SP 对返回图像的输出，记录后训练七参数；父循环随后才 `received.update` |
| CLIP 与 SP 冻结边界 | CLIP eval 且全部参数 `requires_grad=False`；融合输入 detach，优化器只含 raw 七参数 |
| 保留事实 SP | 不覆盖 `_loss`、`cluster_train` 或 gate；`select_queries` 返回 SP 原 logits，SP 拥有全部原配额；新增模型构建隔离随机数 |
| 查询预算与时钟 | 复用 SimATTATrace，父类检查查询、反馈和总正式步数；不在流末冲刷 |
| 语义输入一致性 | 相同 224-square stream tensor 反归一化后做 CLIP 归一化；固定类别顺序逐目录校验 |
| 禁止隐式下载 | 必须是本地 checkpoint 且 SHA256 匹配官方 ViT-B/32，才调用 CLIP load |
| 七类融合归一化 | 类别权重 sigmoid，混合后沿类别维求和归一化；概率输入 detach |
| 初始回退 | 无返回不训练；七权重初始 0.5，代码断言与固定融合 argmax 一致 |
| 无真域边界决策 | 域名只作日志/统计，不参与权重、提示或重置 |
| 查询与返回预测区分 | 缓存查询预测；返回时当前 SP 重新前向；冻结语义概率可复用；缓存计数与 pending 核对 |
| CSV 一致性 | 同一表每行在同一路径生成完整字段；新旧记录分文件，未向父类 gate 行追加不对齐字段 |
| 互补纠错 | 全流评价真值仅在 batch-end 统计；新分支纠错/致错按同一张图的 SP 预测比较 |
| 配对统计 | 先在每 seed 按样本数聚合；然后跨 seed 均值和样本标准差；配对差值先按 seed 相减 |
| 分支完整性 | 结果含 4 arms × 3 phases × 4 domains，共 48 行；resume 核对身份和键；汇总校验 SP 与父结果一致 |
| 双卡与断点 | 每 GPU 至多一个 worker；独立日志/输出；结果标记最后写入；resume 先验配置和代码哈希一致，归档不完整 seed |
| 额外开销 | 保留原正式/影子计数；新增融合步数、CLIP 编码数量；额外返回前向计入父 main_forward，报告共享运行时间和显存 |

## 仍需服务器验证

1. 官方 CLIP 包与现有 PyTorch/torchvision/CUDA 的实际兼容性、显存和吞吐。
2. SP 抽样哈希、伪标签池哈希、正式更新数及准确率与既有 SP 实验的一致性；新增评估前向理论上不改变参数，但没有本地运行证明。
3. 首次反馈前 Fixed-Fusion/Feedback-Fusion 一致；融合训练后只有七参数变化。
4. 三 seed 完整运行、汇总及 `--resume` 跳过完整任务。未本地模拟中断。
5. 语义互补性、固定融合收益与校准额外收益均未知；不把外部预训练提升解释为延迟算法创新。
