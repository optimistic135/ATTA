# 最小冻结源模型实验

预先固定两个问题，不训练、不修改 SimATTA/FCRA，不依赖参考 trace。

1. 低熵错误是否在固定源特征空间局部聚集？每个域、每个预测类别内，
   排除自身，取最多 8 个最近邻。分别报告错误/正确中心的邻居错误率，
   并减去每个中心对应的同域同预测类别随机邻居错误率的精确期望。
   用“两个中心组的超额错误率之差”检查类别/域基准错误率之外的聚集。
2. 主动返回标签能否识别未查询低熵样本中的错误？冻结源模型和查询模型，
   沿用 SimATTA 高熵/增量聚类查询，D=0；每批先评分，后释放反馈。
   复用 FCRA 原始局部门控（512 条缓存、同预测类、cos>=0.8、最多8邻居）。
   当前和所有被查询样本不进入评价池。比较 1-g、预测熵和随机排序的错误检出。

## 预先规定的统计

- 每个低熵图片只记一次，不按训练抽样重复加权。低熵池是所有 entropy<el
  的未查询流样本，不是每批最多约101张的原始伪标签记忆抽样。
- 邻域检查使用完整已采集评价池，属于离线描述，不是在线算法。
- 反馈评分只用当前批之前已经返回的标签；隐藏真值仅用于选择后的 oracle
  查询标签及离线评价，不能用于选样、门控或阈值选择。
- 门控识别按域报告 all / covered 两个范围。covered 指至少一个合格反馈近邻；
  必须同时看覆盖率，不能只报告高覆盖或效果好的子集。
- 报告 AUROC、最低权重/最高熵前10%和20%的 precision、recall、相对随机提升。
  排名边界遇到同分时按并列组比例分配，给出随机打破并列的精确期望，
  不让流顺序决定 g=1 等并列样本的排序；随机排序直接用基准错误率期望。
- 局部聚集的邻居集合为同域同预测类别的 top-k，不另设0.8门限；
  反馈门控保持原始0.8门限。两者回答不同问题，不能混称同一邻域定义。
- 不把共享近邻或重复 seed 中的同一数据视作独立样本，不自动给显著性结论。
  没有正/负例、没有邻居、没有覆盖时输出空值与计数，不补0或伪造结果。

## 解释边界

这是冻结源模型下的可行性诊断，不证明适应中模型的选样轨迹、因果收益或抗遗忘。
高熵查询也是冻结模型产生，不声称复现训练中 calibration_only 的查询记录。
正面结果只支持“局部结构/反馈识别”这一环，完整方法仍需无门控及权重匹配对照。
默认 seed=110 是已有参考种子之一，不能自动称独立确认；另选种子也不等于新数据。
不得根据这些结果再挑阈值后，把同一运行当作独立验证。
