# 静态检查记录

只阅读源代码、官方方法与复用接口，未执行Python、导入、CLI help、compile、测试、实验或训练。

| 项目 | 静态检查依据 |
| --- | --- |
| 源模型加载 | AlgBase复用本项目模型/数据；覆盖train_on_env严格只加载已有源检查点，不回退训练 |
| 骨干冻结 | encoder/fc共同eval和requires_gradFalse；每批1次编码；结束核对源state哈希及所有源梯度为空 |
| 三组初始化 | 相同seed加载相同源权重；隔离随机数构造投影；汇总核对initial_head/source哈希 |
| 向量维度 | 投影[E,N,H]，原型[E,C,H]，logits[E,B,C]；邻域索引产生[E,B,k,C]后平均 |
| 源支持选择 | 只按固定源类别/熵选每类20；返回槽位只依赖ID与释放时钟；三个组支持ID哈希相同 |
| 真值持续保存 | 完整returned/query_cache不随低熵库淘汰；Repair构造支持标签与投票时使用真值；Online/Replay保持源类别 |
| 预测先于更新 | 在线输出在当前入库、新标签释放和头更新之前缓存；first-return batch仍属等待阶段 |
| pending隔离 | 查询缓存只存特征、源类别和熵；query真值仅进入oracle；到期才进入returned |
| baseline类别隔离 | Online正式目标/输出用source标签且known_mask全false；监督损失不启用；可用到期标签做no_grad诊断副本 |
| 一步预算 | 固定每batch一次Adam，不复用SP等待期0额度；两个监督组只加损失，不加optimizer.step |
| 重放匹配 | 私有生成器按seed/step抽完整返回池；三个组记录相同ID，Online不计算监督损失；Replay/Repair次数与draw哈希匹配 |
| 梯度路径 | 特征和目标无梯度；只有投影参数在Adam中；KL/CE按相同成员求和、batch/class归一化 |
| 标签修复诊断 | 同一投影、特征、支持ID，仅改变可用真值标签及投票；诊断no_grad且不进入门控 |
| 目标与输出区分 | 标签修复的hard邻居目标和soft输出分别统计；实际训练目标在入库/释放后另记 |
| 离线评价隔离 | 当前真值仅在本批更新后评价缓存预测/目标；不调参、不改记忆选择、不参与未到期监督 |
| CSV固定字段 | 每表行同一字段模板；空表写表头；所有结果完成后写result标记 |
| 双卡/resume | 九任务一卡一个；独立目录/日志；匹配配置/源码hash后跳过完整任务、部分归档重跑 |
| 结果边界 | 受控TAST-style不是原论文精确复现；支持容量共享；修复同时影响原型和投票；相同步数不等于同FLOPs |

服务器仍需验证：实际导入/数值稳定性；投影和索引维度；源模型/支持ID/抽样哈希；三组首次反馈前预测相同；冻结骨干零梯度；九任务/断点汇总；实际等待期及反馈后收益。静态检查不能证明方法有效。
