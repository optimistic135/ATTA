# 静态审查：FCRA-CSR

仅阅读源码、核对接口和检查差异；未执行Python、CLI、编译、单元测试、推理或训练。以下结论不是运行通过记录。

| 项目 | 静态依据 |
| --- | --- |
| 范围 | 新包fcra_csr；固定D=0/20/50/100 × 三seed；只创建FCRACSR，不运行Relay或其他方法 |
| 复用 | 复用FCRA加载/选样、oracle、GPU调度、进度；仅借用Relay的无状态采样/增强/计数方法 |
| Source/流 | 同一Photo严格checkpoint初始化；STAGES仅Art/Cartoon/Sketch，batch32 |
| 预测顺序 | select_current先固定学生输出，再oracle.release、received.update、train_batch；D=0同样遵守 |
| 标签隔离 | 图只接收received中的图像及真标签；未返回truth保留在oracle；评价标签只用于计分和oracle封装 |
| 当前结构 | 不以学生/EMA分类argmax给图种子赋类；argmax只作离线分歧诊断 |
| 坐标刷新 | 每批重新编码全部窗口与全部历史锚点，同一EMA状态下构图，不读取旧固定源teacher_features作为图特征 |
| 同ID限制 | 当前/锚点ID分别检查唯一；种子匹配排除同ID；扩散后再次清除同ID贡献 |
| 支持来源 | 每个锚点一列，按不同物理图像数和有效权重计数；路径数不增加锚点数 |
| 回退 | 空记忆、断连图、单锚点、类别冲突时valid=false，分类权重为零；结构损失仍可更新 |
| 无类别强迫 | 无证据节点uniform仅为保存格式占位，权重零；不使用低熵硬伪标签或源类别蒸馏 |
| 数值 | 概率归一化、分母epsilon、有限目标/损失检查、非有限梯度报错与裁剪 |
| 梯度 | 构图/EMA参考no_grad；重建、关系与特征一致性仅更新学生；EMA参数不进优化器 |
| 抽样 | 当前训练无重复节点；历史重放保留均匀支持；独立Generator管理增强与采样 |
| 预算 | 每批4当前/混合+26真实重放上限；首次反馈前只有4结构步，未用额度不回填 |
| Pending | 等待期也更新学生，所以每批刷新query anchor特征，不依赖received非空 |
| 输出 | result字段逐项核对spec.METRICS；各域、宏平均、返回率、跨域率、图覆盖、重编码开销均有来源 |
| 汇总 | 12任务完整性检查、三seed样本std、逐seed比率后平均、N/A分母保护、stage_summary |
| 结果保护 | 新输出目录、无流末flush、不覆盖旧实验或已有outputs |

静态修正：所有序列化软目标归一化；拒绝节点的重建类别留空；空查询表头对应实际query_predictions字段；排除环路产生的自身标签贡献；检查锚点物理ID唯一性。

服务器仍需验证：CUDA稀疏矩阵乘法/版本兼容性、checkpoint与数据布局、全骨干梯度、完整历史重编码耗时和内存、图种子覆盖、重建类别质量、三域在线准确率。不同延迟真实更新数不同，重新编码成本也不同，不声称与旧方法预算匹配。
