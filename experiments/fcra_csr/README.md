# FCRA-CSR：当前结构驱动的延迟监督重建

只新增独立实验包，不修改现有 SimATTA/FCRA/Relay/Transport。设计说明见 [方法文档](../../docs/fcra_csr_method.md)。本地未运行 Python、CLI、编译、测试、推理或实验，仅阅读源码和检查差异；结果与性能均待服务器验证。

## 服务器运行

在项目根目录执行：

```bash
git pull --ff-only origin codex/pacs-delayed-feedback
conda activate df-atta
python -u -m experiments.fcra_csr.run \
  --dataset-root datasets \
  --gpus 0 1 \
  --seeds 110 123 456 \
  --output-dir storage/fcra_csr/pacs_acs_bs32_seeds110_123_456
```

单卡使用 `--gpu-idx 0`，与 `--gpus` 互斥。可选 `--checkpoint-dir /path/to/photo_checkpoint`（必须包含 encoder_2.pth、fc_2.pth）；默认沿用 round1 Photo checkpoint。不需要 reference-dir。

只跑 FCRA-CSR 的 D=0、20、50、100 × 三公共 seed，共12次独立初始化的任务，每张GPU一个worker，显示总任务和逐域进度条。输出目录必须不存在；重跑换新目录，避免覆盖结果。

## 固定协议

- Photo 只作为 checkpoint source，在线流仅 Art → Cartoon → Sketch，各域完整访问一次。
- batch=32，训练 minibatch 沿用 PACS 配置（16），延迟单位为全流连续 batch。
- 每批先预测计分，再释放到期标签和训练；D=0 的标签也不改变当批已固定的预测。
- 全流不按域边界重置模型、EMA、记忆或窗口；不使用真实域名做学习决策。
- 物理图像ID来自实际 sampler 顺序和固定域偏移，一个图像只查询一次。
- 保留 FCRA 熵/聚类与 pending 抑制选样。当前学习发生后，无论是否已有返回标签，都刷新 pending 特征。
- 流结束不冲刷队列；pending 不计入已返回标签分母。

## 与逐样本 Relay 的区别

CSR 使用**近期样本之间的两视图稳定邻域图**组织结构，再由多个已返回真标签共同给局部区域定类。它不使用固定源特征空间的逐样本标签投票，不依据当前预测类别排除其他真类别，也不把 EMA 的低熵预测作为图的类别种子。

历史图像与近期窗口每批使用同一 EMA 快照重新编码。图是软的局部社区结构，不额外使用真实域边界或类别KMeans。

无可靠重建目标时，分类损失权重为零，只做增强前后特征关系/特征一致性学习；不强迫不确定样本接受一个类别。主模型在线预测仅使用学生分类器，不在输出端融合图预测。

源模型和 FCRA 初始化/查询模块仍被复用。代码只借用旧 Relay 中无状态的计数、抽样和图像增强函数，不实例化其模型或运行其算法。

## 图重建规则

| 项目 | 固定默认值 |
| --- | ---: |
| 近期窗口 | 4个batch，通常最多128张 |
| 当前互近邻 | 8 |
| 两视图边相似度下限 | 各0.6 |
| 每节点候选历史种子 | 8 |
| 种子相似度下限 | 0.55 |
| 扩散系数 / 次数 | 0.8 / 20 |
| 当前节点最小邻域度数 | 2 |
| 最低传播质量 mass | 0.05 |
| 获胜类别独立真标签数 | 至少2，每个贡献至少5% |
| 获胜类别有效支持度 | 至少1.5 |
| 类别置信度 / 间隔 | 0.8 / 0.2 |
| 邻域类别一致性 | 至少0.7 |

传播保留“节点×原始标签”的贡献矩阵，按独立物理图像计算证据，避免循环传播把一个标签误当成多个标签。排除当前图像的同ID种子，并在扩散后再次清除同ID贡献，防止经环路返回的自身标签参与重建支持计数。该样本已返回的真标签仍可合法用于直接监督重放。

没有种子、没有稳定边、证据冲突或支持不足时拒绝赋类别。诊断中为无证据节点保存的均匀分布仅作序列化占位，分类权重为零；并非训练它输出均匀分布。

## 学习和预算

- 学生更新整个骨干与分类头，沿用 PACS freeze_bn 的运行统计冻结行为；不是旧 Relay 的仅 layer4 更新。
- EMA动量0.99。图及其重建目标在每个batch训练前固定，本批更新期间不随优化器改变，下一batch统一刷新。
- 真实监督 CE 权重1，重建 KL权重0.5，特征关系一致性权重0.1，逐样本特征一致性权重0.05。
- 不做低熵类别锐化，不新增固定源类别蒸馏，不按记忆池大小缩放真实监督。
- 每批4次当前/混合更新，有真标签后另26次真实监督重放，上限30；无真标签时只做4次结构更新，未用额度不回填。
- SGD，lr=0.001，momentum=0.9，梯度裁剪1；非有限损失/梯度报错。
- 完整返回记忆保留；重放每步四分之一位置做当前语义相关检索，其他位置均匀抽样。

该配置未做参数搜索，不声称最优。实际训练步数随反馈可用性变化；每批重新编码历史图像也增加前向成本，相同优化步数不代表相同计算预算。

| 文件 | 内容 |
| --- | --- |
| result.json | Art/Cartoon/Sketch、全流/宏平均、首次反馈前后准确率、反馈与图指标 |
| stages.csv / domains.csv | 各域准确率、查询归属的返回与跨域比例 |
| batches.csv | 更新前准确率、首次反馈前后标记、查询/返回计数 |
| feedback.csv | 查询/到期/返回时刻，物理ID，查询/返回域和阶段，跨域标记 |
| queries.csv / query_predictions.csv | FCRA查询诊断与查询时已固定软预测 |
| graph.csv | 图节点/边数、覆盖率、锚点数、支持度、与EMA预测不同的重建数 |
| reconstruction.csv | 每次图快照中节点的接受标记、类别、贡献数、支持度、一致性及软目标 |
| updates.csv | 真监督/重建/关系/特征损失、采用重建的抽样数、分类分歧、梯度范数 |

## 比例与计数

- returned_pct = 返回数 / 查询数 ×100%，表示流内返回率。
- pending_pct = 未返回数 / 查询数 ×100%。有查询时，二者逐seed之和为100%。
- cross_domain_pct = 跨域返回数 / 返回数 ×100%；pending不进分母。
- cross_stage_pct 在本流与cross_domain_pct相同，因为每域只访问一次。
- positive_delay_returned_pct = 实际等待大于零的返回数 / 返回数 ×100%；D>0应为100%，D=0应为0。
- 无查询或无返回时对应比例为N/A；先逐seed算比例，再平均，不合并计数重算。
- graph_coverage_pct = 各batch图快照中接受的节点出现次数 / 全部节点出现次数；滑动窗口重叠，不是独立图像覆盖率。
- reconstructed_draws 是训练抽样采用重建目标的次数；reconstruction_disagreements 是重建类别与当步强视图学生类别不同的次数，不是“纠对次数”。
- current_updates 与 supervised_updates 可重叠，不能相加当作main_updates。

## 解读边界

首先检查图是否形成、是否有足够独立真标签、重建覆盖率是否过低。只看到图覆盖或分歧增加不能证明准确率提升，需要实际在线计分。

首次反馈前只有结构学习，不凭空生成真实类别监督。结构可能与真实类别不一致、已返回种子也可能不代表当前环境。本实验只运行该方法，不能单独证明优于SimATTA、Relay或其他方法；没有预填准确率或保证性能恢复。
