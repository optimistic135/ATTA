# 局部门控的样本级审计与诊断干预

目标：区分“正确伪标签受到降权”和“降权确实损害后续识别”。
保留现有 calibration_only 训练路径（均匀完整记忆重放，无快速适配器）。
默认选择开发 seed=123、456，每个运行三种模式，共 6 次。新建输出目录，不修改旧结果。

## 服务器运行

```bash
python -u -m experiments.gate_audit.run \
  --dataset-root datasets \
  --reference-dir /path/to/completed-fcra-results \
  --gpus 0 1 \
  --output-dir storage/gate_audit/pacs_d0_sketch
```

单卡改为 `--gpu-idx 0`。如需三个参考 seed，增加 `--audit-seeds 110 123 456`。
参考必须是现有完整基础 FCRA sweep；继承权重哈希、配置、流结构、查询和更新预算校验。
`--num-workers` 默认 0。无需 calibration_only 的旧检查点：三个分支各自重放完全相同的
Art/Cartoon 前缀，只在 Sketch 阶段改变权重。不是从一个序列化检查点恢复所有状态。
Sketch 第一批预测前记录模型、教师、查询/伪标签记忆、反馈缓存和训练 RNG 的指纹，
并保存 sketch_start_model.pt（仅模型及指纹，不是可恢复完整训练的检查点）。
完成时严格比较三个分支的前缀指纹、Sketch 监督及伪监督抽样序列指纹、前缀正确数、
标签数及总更新数。不一致则失败，不把不匹配的运行作为配对结果。不同硬件/非确定性
内核可能导致严格指纹不匹配；应使用一致环境，不得事后放宽校验来追求性能结果。

## 三种模式

| 模式 | Sketch 阶段处理 | 是否为合法 ATTA |
| --- | --- | --- |
| baseline | 保留当前局部门控 | 是，但本次包含额外诊断开销 |
| oracle_correct | 伪标签正确时将其权重恢复为 1；错误样本保留原门控 | 否，隐藏真值诊断 |
| random_count | 从被降权样本中随机恢复同等数量抽样位置的权重 | 否，恢复数量来自隐藏真值 |

三者 Art/Cartoon 均使用原门控。干预前的前向预测不变，恢复只影响后续训练。
随机模式每次 SGD 的恢复数量与 oracle_correct 相同；随机抽样使用独立 CPU Generator
（seed+89017），不消耗主监督/伪监督采样 RNG。按抽样位置而非唯一样本匹配，因此
同一图片在一个 minibatch 出现两次时计两次。不是恢复总权重质量匹配的实验，需同时
查看 restoration_costs.csv。一次随机重复只能提供初步证据，不能排除随机波动。

## 真值隔离与记录

父类新增三个默认空操作/恒等钩子，原入口不改变门控、损失、采样或更新次数。
本诊断子类独立维护 audit_truth/audit_domains，只包含已经预测过的图像，生产 received
和标签 oracle 的读取路径不变。baseline 的隐藏真值仅进入审计记录，不改变损失。
只有两个明确标注的诊断分支在 Sketch 权重干预中使用正确性；不能把它们的分数写进
主方法 leaderboard，也不能将 oracle 规则部署为不使用隐藏真值的算法。
当前步骤真值先用于指标和审计台账，再生成伪标签、释放标签、更新模型；新真值不
改变本批已经固定的预测。审计不重新运行模型前向，不额外做训练或采样；邻域统计
只使用固定特征，额外计算和压缩写盘会增加运行时间，因此不把该时间与旧实验直接比。

pseudo_draws.csv.gz 每次抽样记录：

- 当前 step/domain/iteration、抽样位置、sample_id 和样本来源域；
- 伪标签、离线评价真值、是否正确；
- 原始 gate、干预 effective_gate、当前模型未加权 CE；
- 合格反馈邻居数、相似度权重总支持量、平均相似度；
- 相似度加权反馈错误比例、反馈域与伪样本来源域不一致比例；
- 反馈域与当前处理域不一致比例、平均反馈年龄；
- neighbor_events：实际 top-k 邻居的 anchor ID、相似度、对错、域与返回时刻。

样本 ID 来自原伪标签选择器返回的 current-batch 位置，逐次断言与伪标签记忆对齐。
邻域审计复用相同教师特征、同预测类别限制、0.8 门限和最多 8 邻居；不把评价域标签
作为门控条件。邻居教师对错只对应已查询/已返回样本，不是无偏域正确率。

## 固定分组与输出

运行成功会自动生成 report.md。也可以只重做离线汇总（不加载检查点、不推理）：

```bash
python -m experiments.gate_audit.analyze --results-dir storage/gate_audit/pacs_d0_sketch
```

分组在实验前固定，不依据测试准确率选择阈值：

- 邻居数：0、1–2、3–8；
- 支持量 sum(exp((cos-1)/0.1))：0、(0,1]、(1,3]、>3；
- 跨来源域反馈加权比例：无支持、<0.5、>=0.5。

| 文件 | 内容 |
| --- | --- |
| conditions_draw_weighted.csv | baseline 按当前域、伪样本来源域、条件、正确性分组；记录次数、平均权重/降权、被削弱 CE |
| conditions_sample_weighted.csv | 组内先对每个独立样本的抽样求均值，再对样本等权平均 |
| intervention_deltas.csv | 每个 seed 的 Sketch/Stream 配对差值 |
| restoration_costs.csv | 两种干预恢复的抽样次数与总权重质量 |
| report.md | 配对性能、正确/错误伪标签权重概览及解释边界 |
| runs.json/manifest.json | 每次结果、运行状态、协议与参考哈希 |

同一独立样本可以在不同 step 进入多个条件分组；sample-weighted 不是每组只记录首次。
伪标签在当前固定教师下一般不会改变，但记录与记忆条目逐项关联，不重新生成标签。
不对海量重复抽样做独立样本显著性检验。移除 CE 只是优化信号量，不是梯度范数或
泛化风险，不能把训练 CE 降低解释为性能提高。

## 结论边界

正确标签平均权重较低，只说明它被削弱，不能证明损害。Oracle 保护优于 baseline 且
优于随机保护，可支持针对性误降权解释，但还需排除恢复权重质量差异和随机控制波动。
该实验不能解释进入 Sketch 前已形成的两种算法状态差异，也不能识别某一测试图片的
个体因果修复/破坏。域来源分组仅作离线诊断，不是合法在线方法的域 ID 路由。

开发用的两个 seed 不能充当新机制的独立确认集。后续应只改被证据支持的一项机制，
在未参与设计的 seed 和另一数据集上验证，不把诊断 oracle 当作新方法。

本次代码只做静态阅读、时序/索引/随机数/预算/字段追踪和 Git 差异检查；没有在本地
运行 Python、测试、模型、离线分析或实验。实际正确性及性能均待服务器验证。
