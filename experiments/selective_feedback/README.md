# 选择性反馈纠正：PACS D=100

## 实验问题

理想目标诊断表明：纠正当前目标的类别内容可恢复局部收益，但真实可部署的校正分支也会破坏正确预测。本轮只检验：**延迟真值能否训练一个低维可靠性判断模块，使当前目标的选择和拒绝更有效？**

固定 Photo(source) → Art → Cartoon → Sketch、batch32、D=100、seed=110/123/456。三组×三seed，共9次。不开其他延迟、参数搜索或新数据集。旧实验与已有结果不修改。

## 三个对照组

| 组别 | 当前目标动作 | 模块训练 |
| --- | --- | --- |
| SP-ATTA | 原SP完整路径 | 无 |
| SP-Select | 接受可靠源目标，或拒绝 | 同样训练校正分类头与可靠性模型，但不使用校正目标 |
| SP-Correct | 接受可靠源目标、选择校正目标，或拒绝 | 与SP-Select相同 |

主要比较是SP-Correct−SP-Select：两组保持查询、反馈、模型初始化、模块训练、窗口抽样和预算分配一致，只改变是否允许纠正。SP-Select对SP是组合改进比较，同时包含窗口目标及预算分配，不能解释成纯筛选消融。

源模型保持固定。另复制源线性分类头hψ，以已返回真值学习；在线适应模型承担正式预测。此处不把SimATTA表述成教师—学生框架。

## 最小方法

### 1. 低维可靠性模型

设源概率qS与校正概率qR，使用2C+8维特征：

- 两组完整类别概率，共2C维；
- 两组最大置信度、top1−top2间隔、归一化熵，共6维；
- 两分支是否同类别、归一化JS散度，共2维。

PACS共7类，输入22维。可靠性模型为Linear(22,2)，权重与偏置零初始化，输出sigmoid分数sS/sR。初始化在独立RNG上下文中，避免改变SP随机轨迹。

每次查询保存当时的特征、两分支类别、可靠性分数与原置信度。标签返回后才形成监督：

rS = 1[argmax(qS_query)=y]

rR = 1[argmax(qR_query)=y].

用完整已返回查询记录训练BCE + 0.01×mean(weight²)，SGD lr=0.05、momentum=0，不做类别重采样。使用查询时的状态，不用训练后的预测替代原预测。

分数只代表模型对查询分布的估计，不保证在当前分布上已校准。当前类别真值不进入可靠性训练。

### 2. 当前目标的选择与拒绝

维护最近4批图像，不按域边界重置。固定源特征缓存，校正头每批重新计算概率。强视图只做水平翻转。

先满足对应分支置信度>=0.9、弱/强视图类别一致；再执行：

- 历史返回记录少于32条或可靠性更新不足8次：全部拒绝当前辅助目标。
- SP-Select：sS>=0.8才接受源目标，否则拒绝。
- SP-Correct：校正类别与源类别不同、sR>=0.8、sR−sS>=0.1，且校正分支通过基础筛选时，使用校正目标；否则，源分支通过筛选且sS>=0.8时使用源目标；都不满足则拒绝。

两分支同类别时保留原源分布，不用校正概率无故替换它。可靠性阈值、margin和warmup全部固定，不根据测试正确率调节。

### 3. 保留历史SP路径，小比例引入当前目标

原SP目标：

L_SP = L_truth + λ_t L_history，λ_t∈{0,0.25}.

原SP门控仍只验证历史伪监督，逻辑不变。当门控接受且本次当前抽样有可靠目标时：

L = L_truth + λ_t[(1−ρ)L_history + ρL_current]，ρ=0.25.

L_current = mean_batch[m KL(stopgrad(q_selected) || p(x_flip))].

当前项按整个抽样batch大小归一化，真实监督系数固定1。名义辅助总系数不增加；当前项最大系数0.0625。没有可靠当前目标时学生损失回退原SP历史目标；原SP拒绝辅助时只用真实监督。

这是小比例替换，不是把新损失叠加在全部SP损失上。回退的是损失规则，不保证整条轨迹精确等同于SP，因为模块仍消耗训练额度，早期参数也可能已经不同。

### 4. 正式预算与时序

复用原SimATTA D100查询ID、时钟、源检查点与逐批更新额度。每个有新标签返回的批次，最后两个正式额度分别训练校正头和可靠性模型；只有一个额度时只训练可靠性模型，其余用于在线适应模型。

校正头使用完整真实记忆和源特征，SGD lr=0.001、momentum=0，源参数锚定系数0.01。可靠性模型使用完整已返回查询记录，私有随机抽样。两组新方法的模块训练完全相同。

每批先预测；使用旧模块状态选择当前目标、运行原SP门控及局部诊断；随后将合法返回标签加入记忆；学生先更新，分类头与可靠性模型最后更新，从下一批影响选择。

student_updates + head_updates + reliability_updates = reference quota.

影子候选另计开销，不混入正式总预算。正式步数相同不等于FLOPs相同。SP保留全部原学生额度；新方法把部分额度转给模块，因此不能声称“模块完全免费”。

## 三级验证

1. **目标质量**：实际训练抽样中的目标正确率、源目标在同一图像上的正确率、净目标纠错，以及覆盖率和实际训练draws。不能用几乎零覆盖的高准确率声称成功。
2. **局部模型净纠错**：保留五个时钟探针，对同快照/抽样做TRUE、HISTORY、SELECTED三个一步候选，冻结评分下一10批。HISTORY=真实监督+0.25历史辅助；SELECTED=同样总系数下的历史/当前混合。SELECTED−HISTORY才隔离替换历史辅助的效果；SELECTED−TRUE还包含原历史辅助收益。
3. **整流表现**：SP-Correct是否超过SP-Select和SP；Cartoon/Sketch分别报告。首次反馈前不更新，D100的Art不预期改善。

局部探针固定测试辅助系数0.25，不要求原SP门控接受，因此是潜力诊断，不等于部署时收益。另报告实际抽到可靠目标的active探针；零选择时SELECTED退化为HISTORY，不能把历史项收益归功于新模块。

各方法后续模型状态可能不同；局部候选只保证同一方法、同一触发事件内部的快照与抽样匹配，不能把跨方法局部均值差直接解释成纯目标差异。

## 服务器命令

```bash
git pull --ff-only origin codex/pacs-delayed-feedback
conda activate df-atta
python -u -m experiments.selective_feedback.run \
  --dataset-root datasets \
  --reference-dir storage/simatta_rootcause/pacs_d100_bs32_seeds110_123_456 \
  --gpus 0 1 \
  --seeds 110 123 456 \
  --output-dir storage/selective_feedback/pacs_d100_seeds110_123_456
```

参考目录是原始SimATTA D100根因诊断，含D100/seed_110等，不是SP、feedback_teacher或oracle结果目录。每GPU同时一个任务，有逐域和总进度条。单卡替换为`--gpu-idx 0`；支持`--checkpoint-dir`、`--num-workers`。

同目录续跑加`--resume`：停止旧进程后，完整“方法×seed”校验跳过，未完成任务从头执行，旧文件及日志移至`_resume_archive/UTC时间/`。不能用旧方法的目录续跑本方法；更改算法或默认参数应使用新目录。

## 输出与读表

- 根目录`summary.md/csv`、`per_seed.csv`、`paired.csv`、`paired_summary.csv`：准确率、反馈数量/比例、预算、机制指标和配对差。
- `domain_per_seed.csv`、`domain_summary.csv`：Cartoon/Sketch分开的目标与局部收益；目标按图像实际域统计，未来按评分批次域统计。
- 每任务`feedback_quality.csv`：查询时描述符、类别、分数/置信度，以及返回真值；待标签返回后评分，可比较Brier，越低越好。它只评价已返回主动查询样本，不是当前总体校准证据。
- `selection.csv`：warmup状态、可选择与实际使用数量。
- `target_quality.csv`：选择动作、真实监督完成后的离线正确性、实际训练draws；评估真值不回流训练。
- `selected_probes.csv`、`selected_future.csv`：局部候选完整性、改对/改错及域。
- 原SP的batches/domains/feedback/gates/updates/budget/compute等保留。

目标准确率和净纠错按实际训练draws加权；覆盖率按窗口—图像观测计算，会包含重复图像。每个seed内先汇总，跨三个seed报均值±样本标准差及有效n。零选择或没有active完整探针时记N/A，不填零准确率。

汇总检查：三组正式索引/伪池哈希、查询返回及总额度相同；后两组额外检查反馈描述符/标签哈希、当前图像抽样哈希和各模块步数相同。门控规则相同但模型不同后接受决定可以不同。

## 预先约定的判断

- 可靠性分数Brier改善但几乎没有选择或目标质量未改善：不能声称模块有效。
- SP-Select有效，SP-Correct没有额外收益：保留筛选，停止扩大校正分支。
- 目标质量改善但SELECTED−HISTORY不为正：先检查当前辅助强度/参数范围，不堆叠模块。
- 目标质量、局部增益与整流表现都改善：再验证D=20/50与D=0。
- 全部拒绝时不根据测试真值临时降低阈值；记录覆盖瓶颈，不能强行把结果包装为性能提升。

历史主动查询有选择偏差，风险分数可能无法迁移到当前域。Brier改善也不等于排序或选择能力足够。该实现是一项可证伪的最小方案，不保证超过SP或恢复D0，不宣称已成立的论文创新。
