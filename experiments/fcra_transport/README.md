# FCRA-Transport：延迟真反馈校准的历史监督迁移

独立新增实验包，不修改现有 SimATTA、FCRA 或其他实验入口。方法设计见 [设计文档](../../docs/delayed_feedback_calibrated_transport.md)。

本地只做源码和差异检查；尚未执行 Python、CLI、测试、推理或训练。这里不提供预填结果，也不保证方法优于既有 FCRA。

## 服务器运行

在仓库根目录、已有 df-atta 环境中执行：

```bash
git pull --ff-only origin codex/pacs-delayed-feedback
conda activate df-atta
python -u -m experiments.fcra_transport.run \
  --dataset-root datasets \
  --gpus 0 1 \
  --seeds 110 123 456 \
  --output-dir storage/fcra_transport/pacs_recurrent_bs32_seeds110_123_456
```

每张 GPU 同时一个任务，显示总任务和逐阶段进度条。单卡改用 `--gpu-idx 0`，与 `--gpus` 互斥。可用 `--checkpoint-dir /path/to/checkpoint` 指定包含 `encoder_2.pth`、`fc_2.pth` 的 Photo 检查点目录；默认沿用项目 round1 Photo 检查点。

`--dataset-root` 指向 PACS 文件夹的父目录。输出目录必须不存在；重跑时换新目录，避免覆盖结果。不需要 `--reference-dir`，也不会启动旧版基线或额外消融。

固定运行 D=0、50、100，每个延迟共用三个 seed，共九个独立任务。默认 seed 为 110、123、456。每个任务从相同 Photo 权重独立初始化。

## 测试流与图像身份

- Source：Photo 检查点。初始 Photo 不作为一个在线评测阶段，也不额外训练。
- 在线阶段：`Art_1 → Cartoon → Sketch → Art_2 → Photo`。
- batch size=32，训练 minibatch 沿用 PACS 配置（当前为 16）。
- 每阶段使用该域的完整 ImageFolder。Art 第二次使用相同物理图像和该 seed 下相同顺序。
- 图像 ID 为域内 ImageFolder 索引加固定域偏移；全流一个图像最多查询一次。重复访问仍可预测，但不会再次付费查询已查询图像。
- Art_2 是重复图像的再访问，可能受已经获得的该图像标签帮助；不能当作独立未见测试集。
- 末尾 Photo 是回到 source 的在线表现，其中图像可能参与过原检查点训练；不能解释成独立 source 泛化精度。
- 时钟、模型、优化器、记忆、风格窗口和反馈证据跨阶段连续，不用域边界重置。
- 每批先预测，再释放标签和训练；D=0 的审计也在新标签释放前完成。流末不冲刷 pending 队列。

## 实现模块

### 1. 当前风格与历史类别匹配

在 ResNet `network.layer1` 上提取通道均值、标准差。EMA 教师的风格统计停止梯度；固定源教师的归一化深层特征用于语义检索。

近期窗口最多 512 个样本，条目最多保留 16 个 batch。所有条目描述环境；只有置信度至少 0.9、原图与水平翻转预测一致的条目可提供迁移风格。均值/标准差只是风格代理，不能保证与语义完全分离。

主模型每步从完整已返回记忆抽样；其中四分之一位置尝试按当前可信类别和语义相似度检索，其余位置均匀抽样。对抽中的历史样本，寻找真实标签与当前预测类别一致、语义相近的风格提供者。无可靠同类提供者时，回退原始监督。

### 2. 三种迁移动作

候选强度固定为 `0, 0.1, 0.3`。历史特征先按自己的通道统计标准化，再将均值与对数标准差向当前风格插值。

迁移强度大于零时，真实监督为 `0.5 × 原始 CE + 0.5 × 迁移 CE`；强度为零时只计算一次原始 CE。梯度经过历史特征和主模型，当前风格统计不接收梯度。

保留 FCRA 的固定源教师低熵伪标签记忆和返回真标签校准门控；真实/伪监督混合系数沿用原 FCRA 的记忆大小规则。本轮不引入新的当前无标签一致性损失，避免同时改变多个机制。

### 3. 隔离的候选更新审计

每五个 batch 最多审计前四个新查询样本。查询样本不必低熵，但必须在近期窗口存在可信同预测类别的风格提供者，并已有同类已返回历史监督；否则跳过。

每个审计样本，从语义最接近的最多四个同类历史样本构造一个训练 minibatch。三种候选使用同样的历史样本、伪监督 minibatch、初始模型、优化器动量和随机状态，分别执行一步短更新，然后在原始无标签查询图像上保存七类软预测。

临时模型随后丢弃，不替换在线预测、不写回主模型。候选参数、BatchNorm 缓冲区和优化器隔离；Python、NumPy、CPU/CUDA 随机状态恢复。审计和主训练采样使用独立 CPU Generator。

当前实现的审计是同类别局部训练干预，主模型训练是混合类别记忆重放。审计结果向主训练迁移仍是研究假设，不代表严格复现一整段主模型训练轨迹。

### 4. 延迟真反馈决策

查询标签返回后计算 `clip(log p_action(y) − log p_original_update(y), −2, 2)`。保存的上下文和查询时预测类别不被返回真类别回写。

按类别、归一化风格差异、可靠性、不确定性和审计年龄聚合证据；类别统计向全局收缩。有效支持度至少 3、衰减权重总和至少 1，且扣除波动惩罚后超过 1e-4，才选择迁移，否则执行原始重放。

这是保守启发式，非统计置信保证。查询样本有选择偏差，奖励不是全体样本无偏收益；它评价当时的局部短更新，而非当前环境或长期流准确率。

首次可用审计奖励可能晚于首次反馈：必须先有历史真标签才能审计，审计查询再等待一个 D。长延迟时应检查奖励是否足够、策略是否实际选择了迁移。

## 固定默认值与预算

| 项目 | 默认值 |
| --- | ---: |
| 流 batch | 32 |
| 候选强度 | 0 / 0.1 / 0.3 |
| EMA 动量 | 0.99 |
| 可信阈值 | 0.9 |
| 近期窗口 | 512 样本 / 16 batch |
| 审计间隔 | 5 batch |
| 单次最多审计查询 | 4 |
| 每候选审计更新 | 1 |
| 每批主训练＋审计更新上限 | 30 |
| 证据缓存 | 2048 事件 |
| 证据年龄尺度 | 200 batch，从审计时刻起 |
| 奖励截断 | ±2 |
| 全局先验 / 类别收缩 | 4 / 8 |
| 波动惩罚系数 | 0.5 |
| 优化器 | SGD，momentum=0.9 |
| 学习率 | 沿用 PACS SimATTA，当前 0.001 |

主优化器跨 batch 保留动量。每审计一个样本耗费三次候选更新，从当批 30 次额度中扣除；最多四个样本对应 12 次审计和 18 次主更新。无审计时最多 30 次主更新。无已返回标签时跳过监督更新，未用额度不累计。

这是一套预先固定的更新上限，**不复用原 FCRA 的早停次数，也不声称 D=0 与旧 FCRA 数值相同**。不同延迟的实际总步数可能不同，且相同优化步数不等于相同 FLOPs。本次只运行方法自身，不能直接做预算匹配的优越性结论。

## 输出与统计定义

根目录提供 `manifest.json`、`per_seed.csv`、`summary.csv` 和 `summary.md`。manifest 记录 Git revision、Photo 检查点 SHA256、seed、设备、测试阶段与协议。每次任务的 `settings.json` 记录方法默认值与 SimATTA 参数。

汇总表是三个 seed 的均值 ± 样本标准差（ddof=1）。只在九次任务完成后生成最终汇总；失败任务的日志和已完成结果会保留。

| 文件 | 内容 |
| --- | --- |
| `result.json` | 各阶段、全流、宏平均、反馈、审计与预算指标 |
| `stages.csv` | Art_1、Cartoon、Sketch、Art_2、Photo 五阶段准确率与按查询阶段归属的反馈统计 |
| `domains.csv` | 合并两个 Art 后四个语义域的准确率和反馈统计 |
| `batches.csv` | 更新前准确率、首次反馈前后标记、查询与返回数 |
| `feedback.csv` | 查询/到期/返回时刻、物理 ID、查询/返回域和阶段、跨域/跨阶段标记 |
| `queries.csv` | FCRA 熵筛选与 pending 抑制统计 |
| `audit_predictions.csv` | 候选软预测、固定上下文、当时预估奖励与决策 |
| `audit_rewards.csv` | 真标签返回后形成的动作奖励，及此前已固定的预测奖励 |
| `decisions.csv` | 主训练各动作样本数、有效支持度、监督权重与损失 |
| `budget.csv` | 每批额度、主更新、审计更新、未使用额度及累计计算计数 |
| `compute.json` | 主模型、源教师、EMA、候选审计的编码器前向/反向调用及图像数、流耗时 |

- Stream accuracy：五阶段所有遇见样本的加权准确率，重复图像按遇见次数计入。
- Stage macro：五个阶段准确率等权平均。
- Domain macro：先合并两个 Art 的样本计数，再对 Art、Cartoon、Sketch、Photo 四域等权平均。
- Cross-domain ratio：查询域与返回域不同的已返回标签数 / 已返回标签数。
- Cross-stage ratio：查询阶段与返回阶段不同的已返回标签数 / 已返回标签数。Art_1 返回到 Art_2 可跨阶段但不跨域。
- Pending 不进入比例分母。无返回时比例为 N/A；summary.csv 保存有效 n。
- 比例先逐 seed 计算再平均，不将三个 seed 的计数合并后计算比例。
- 首次返回 batch 的预测仍归入“反馈前”，因为其预测先于当批反馈。
- `transport_updates` 是至少包含一个迁移样本的主更新步数，不是迁移样本数。
- 计算计数覆盖编码器调用及图像数，不等于 FLOPs；CUDA 显存与流耗时分别记录。模型初始化不计入流耗时。

## 如何解读结果

首先检查 `audited_queries`、`returned_audits` 和 `transport_updates` 是否足够。若动作几乎全为零，说明当前决策没有获得或采用足够迁移证据，不能将结果解读成有效验证了风格迁移。

再检查保存的预估奖励与之后返回奖励是否一致，以及 Art_2 和 Photo 返回阶段的表现。审计软损失改善不能代替在线准确率改善。单个方法在三个延迟下的结果只描述延迟敏感性，不能单独证明优于 SimATTA、FCRA 或固定风格迁移。
