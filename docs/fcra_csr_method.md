# FCRA-CSR：当前结构驱动的监督重建

## 研究假设

历史真标签仍携带类别知识，但历史图像与当前环境可能错位。本方法不对历史图像做风格替换，而是先利用当前样本形成稳定的局部结构，再将已返回真标签映射到该结构，为可靠区域重建监督。该假设尚未由实验验证，不保证长延迟准确率恢复。

在线协议为 Photo(source) → Art → Cartoon → Sketch，batch=32，D=0/20/50/100，三个公共seed。当前预测始终先于当批标签释放与训练。无提前标签、无快速通道、无真实域边界重置。

## 模块一：不依赖类别伪标签的当前结构

保留最近四个batch图像，用同一个EMA教师快照分别编码原图与翻转图，得到归一化特征 \(z_i^w,z_i^f\)。

只有互为近邻、且两视图相似度都达到阈值的节点之间才连边：

\[
W_{ij}=\exp\left(\frac{(z_i^w)^Tz_j^w+(z_i^f)^Tz_j^f-2}{2\tau}\right)
\mathbb1[\text{mutual-kNN and both views pass thresholds}].
\]

去除自环并按行归一化为 \(P\)。该图表示软的局部社区，不假设一个社区天然对应某个真实类别，也不依据模型argmax给社区命名。

## 模块二：真标签溯源扩散

对全部已返回图像用同一EMA快照重新编码，避免历史特征与当前特征处于过时坐标。每个当前节点检索有限个相似历史种子，形成行归一化种子关联矩阵 \(B\)。同一物理图像的当前节点和标签种子之间不建立直接关联。

传播的是节点到**各原始标签图像**的关联，而不只是类别概率：

\[
R^{(0)}=B,
\qquad R^{(l+1)}=(1-\alpha)B+\alpha PR^{(l)}.
\]

保留独立的种子列，防止一条标签沿多个路径循环后被误计为多份支持。扩散结束后再次清除节点自身物理ID对应的种子贡献，阻止自己的标签经环路返回。

按行归一化传播贡献 \(\bar R\)，再用已返回真实类别构造目标：

\[
q_i=\sum_h\bar R_{ih}\operatorname{onehot}(y_h).
\]

没有任何真标签连接的区域保持无监督状态。当前预测类别不参与种子类别过滤，因此真标签可以纠正模型原先的错误分类。

## 模块三：多证据一致的接受规则

令获胜类别为 \(c_i=\arg\max q_i\)。只接受同时满足以下条件的节点：

1. 两视图稳定图中的度数至少2，传播质量至少0.05。
2. 至少两个不同物理图像的真实标签支持获胜类别，每个贡献至少5%。
3. 获胜类别有效支持度至少1.5：

\[
n_i^{eff}=\frac{(\sum_{h:y_h=c_i}\bar R_{ih})^2}
{\sum_{h:y_h=c_i}\bar R_{ih}^2+\epsilon}.
\]

4. 最高类别概率至少0.8，前两类差值至少0.2。
5. 当前邻域中至少0.7的加权类别支持与该节点一致；无种子邻居不参与有效类别支持。

通过条件后，监督权重为类别置信度、邻域一致性与传播质量的乘积；不通过则分类权重为零。这里的“不同标签证据”指不同物理图像，不代表样本之间统计独立。

## 模块四：监督重建与结构保持联合更新

学生训练整个编码器与分类头，保留原PACS BatchNorm运行统计冻结设置。

\[
L=L_{true}+0.5L_{reconstruction}+0.1L_{relation}+0.05L_{view}.
\]

- \(L_{true}\)：完整已返回记忆的真实标签CE，防止丢失历史分类知识。
- \(L_{reconstruction}\)：强增强当前图像到可靠重建目标的加权KL；拒绝赋类的样本此项为零。
- \(L_{relation}\)：匹配EMA参考特征与学生强视图特征的样本间相似关系分布，排除自相似项。
- \(L_{view}\)：学生强视图与EMA参考特征的逐样本余弦一致性。

不使用低熵类别锐化，也不把无证据图像训练成均匀类别分布。首次反馈前只执行关系和特征一致性学习；这可以约束当前结构，但不保证产生正确类别知识。

每批先固定图快照与目标，再执行四次当前/混合更新；有真标签后额外执行26次真实重放。图在下一batch重新编码更新，不跟随本批每一步梯度即时改变。

在线输出仅由学生分类器产生，图只提供训练监督，不额外融合推理结果或改写已记录预测。

## 贡献候选与验证边界

本方法拟验证的是：当前结构能否将迟到的历史类别监督转换为更适合当前图像的训练目标。互近邻、EMA、图扩散和一致性学习都是已有技术组件，不单独声明新颖性或最优性。

必须检查结构是否稳定、种子是否覆盖当前类别、重建覆盖率是否足够，以及后续在线准确率是否改善。图上多数一致仍可能一致地错；特征空间不可靠、类别混杂、返回标签偏置时，方法可能退化为只进行结构学习。

本次只运行该方法的四个延迟，输出各域准确率、三域平均、流内返回率、跨域比例、pending及图诊断。未运行本地实验，不预填结果，也不以单方法结果证明优于已有方法。
