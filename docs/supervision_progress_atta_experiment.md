# SP-ATTA：真实监督进度保护的延迟适应——简化实验方案

> 状态：已新增experiments/sp_atta实现，尚未运行验证。本文件依据用户提供的SimATTA D=100诊断结果及现有代码编写，不预设提升，也不声明首次提出。运行命令见[README](../experiments/sp_atta/README.md)。

## 1. 先进性评价：优势是机制针对性，尚非性能结论

当前最有价值的变化是从“猜测历史标签失效”转向“测量历史监督是否被原训练目标削弱”。已有诊断中，TRUE相对SKIP为 +2.14 ± 1.84 pp，PSEUDO为 −0.11 ± 0.18 pp，TRUE−MIX为 +1.06 ± 0.42 pp；初始梯度余弦约0.00 ± 0.04。它们支持研究监督缩放与辅助监督价值，尚不能单独确认唯一根因。

SP-ATTA有两个贡献候选：

1. **纠错主项不被稀释**：真实监督系数固定为1，让标签到达后的有效更新强度不再随伪标签池大小下降。
2. **辅助监督接受真实检验**：用新返回且尚未参加候选训练的标签，检验伪监督相对纯真实更新的增量价值。

第一点本身是简单修正，创新性有限；第二点才是方法贡献候选。若第二点不能超过纯真实监督和固定辅助权重，则不应强行声称自适应机制有效。

已有[PCGrad](https://arxiv.org/abs/2001.06782)和[CAGrad](https://arxiv.org/abs/2110.14048)研究梯度协调，本方法不把梯度投影作为主要机制。[IWMS](https://arxiv.org/abs/2312.00923)已研究标签延迟下的历史监督重放，因此“保留/检索历史标签”也不是单独创新点。这里的差异在于以纯真实更新为参照，用延迟反馈检验辅助目标的增量作用；完整新颖性仍需进一步文献比较。

## 2. 方法：只有两个模块

### 模块一：真实监督主导

原目标：

\[
L_{mix}=\alpha_tL_T+(1-\alpha_t)L_P.
\]

新目标：

\[
L=L_T+\lambda_tL_P.
\]

保留原SimATTA模型、查询、完整记忆、伪标签生成和优化器，不增加适配器、图传播或风格迁移。真实监督不按记忆大小重新缩小。

### 模块二：新反馈增量检验

在新标签返回的batch，记新反馈为F、此前真实记忆为M。标签返回后可合法参与算法，但不能改变当前batch已经记录的预测。

从相同模型和优化器状态建立两个一次更新的临时候选：

\[
\theta_T=\operatorname{Step}(\theta,L_T(M)),
\]

\[
\theta_{T+P}=\operatorname{Step}(\theta,L_T(M)+\lambda_0L_P).
\]

候选使用相同真实抽样、同一初始动量、相同学习率和可对齐随机状态。F不参与候选训练。用F计算：

\[
G=\operatorname{CE}_F(\theta_T)
-\operatorname{CE}_F(\theta_{T+P}).
\]

若G大于预先固定的安全裕量，则本batch采用lambda_t=lambda_0，否则lambda_t=0。候选均丢弃，主模型不继承候选参数；随后F全部并入完整记忆，用选定目标执行正式训练。

初始建议固定lambda_0=0.25、安全裕量=0.001，属于未调参的实现起点，不做搜索。没有新反馈、没有既往真实记忆或没有伪标签时，回退纯真实监督；真实记忆也为空时沿用原SimATTA的等待行为。

该模块不需要新的快速标签通道，不另外查询审计样本。它使用当前已经返回的反馈做即时检验，但F对应历史环境，并不等于当前域的无偏验证集。少量新反馈也可能使选择不稳定，需要记录而非掩盖。

## 3. 先做一个很小的根因补充

现有TRUE/MIX比较同时改变了真实监督的系数和伪监督项，还没有分开两种解释。沿用现有五个诊断窗口，仅增加一个分支：

\[
L_{TRUE\text{-}scaled}=\alpha_tL_T.
\]

同一snapshot、同一真实抽样、同一学习率与十步更新，再评价相同后续十个batch。

| 补充结果 | 更支持的解释 |
| --- | --- |
| TRUE-scaled接近MIX，且均低于TRUE | 真实监督缩放是主要可疑机制 |
| TRUE-scaled高于MIX | 伪监督还产生额外的不利影响 |
| TRUE-scaled与TRUE接近，但MIX较差 | 重点研究辅助目标使用，而不是把缩放当作主因 |

这里只复用D=100、三个seed的原诊断，不增加其他delay或参数搜索。若新增分支不支持当前解释，应先修正方法假设，不直接扩展实验。

## 4. 主验证：四组就够

只先验证PACS D=100，Photo(source) → Art → Cartoon → Sketch，batch=32，seed=110/123/456。

| 组别 | 正式训练目标 | 主要作用 |
| --- | --- | --- |
| Original-MIX | alpha L_T + (1-alpha)L_P | 原目标参照 |
| TRUE-only | L_T | 判断删除伪监督是否已经足够 |
| Fixed-Aux | L_T + 0.25 L_P | 判断仅取消真实监督缩放是否足够 |
| SP-ATTA | L_T + lambda_t L_P | 判断新反馈检验有无额外价值 |

先做四组×三个seed，共12条主轨迹；不同时增加数据集、模型或其他模块。只有D=100结果支持假设，再考虑其他delay。

### 公平比较

- 使用已有原SimATTA D=100运行的feedback.csv固定查询ID和查询时刻，保持返回时刻、标签数量一致。
- 使用phases.csv记录的逐batch正式更新次数，避免早停差异替代方法效果。
- 相同seed使用同一Photo checkpoint、数据顺序和预生成的真/伪监督抽样；不改变训练minibatch。
- 为比较选择机制，可让四组都执行相同的两候选检验；前三组忽略检验结果，仍使用自己的固定目标，只有SP-ATTA采用决策。
- 候选开销与正式训练分开记录。相同更新数不等于相同FLOPs，TRUE-only与双分支目标的前后向成本仍不同；同时报告图像处理数和耗时。
- 原始主结果仍可作为参考，但上述固定查询/固定更新协议下的Original-MIX应重新运行，不能直接拿不同预算的旧数字替代。

## 5. 只保留必要指标

主表：Art、Cartoon、Sketch、三域等权平均、全流准确率，均为三个seed均值±样本标准差。重点看SP-ATTA相对TRUE-only和Fixed-Aux的逐seed配对差。

辅助表：返回数、返回率、跨域返回比例、pending、正式与候选更新次数、耗时。

机制诊断只记录三项：

1. 每个反馈batch的G、新反馈样本量和辅助目标采用率。
2. 原alpha、实际lambda及真实监督更新强度。
3. 相同局部窗口下，加入辅助目标相对纯真实目标的后续净纠错。

G只负责当时的在线选择；后续真标签仅用于离线计分，不能回流改变当时决策或调参。反馈前后样本域不同，不能直接用两段准确率差证明反馈有害。

## 6. 成功与失败如何判断

- SP-ATTA超过Original-MIX，但不超过TRUE-only：支持真实监督主导，不支持自适应检验的额外价值。
- Fixed-Aux已经与SP-ATTA相当：主要贡献应收缩为目标尺度修正，不能把提升归因于反馈决策。
- SP-ATTA在逐seed配对结果中优于TRUE-only和Fixed-Aux，且辅助目标采用时有更好的后续净收益：支持核心机制。
- 辅助目标几乎从不被采用：方法退化为TRUE-only，不能仅凭结果较好就声称门控有效。
- 三seed只提供初步重复性证据，不凭汇总均值宣称统计显著或普遍有效。

本方案不解决首次反馈前的全部错误，也不保证恢复D=0。论文贡献应落在“迟到真实监督的有效更新强度及辅助监督增量价值”，而不是宣称消除了标签延迟。
